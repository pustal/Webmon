USB drives

Webmon keeps heavier files (the game, ROMs, saves, mods) in a Webmon folder on a USB drive when there is one. ROMs and saves in RetroArch-style roms and saves folders at the root of a drive also show up in the game's file picker.

Memory for heavy mods

webOS restarts the app when the TV runs out of free memory, which big mods (voxel worlds building their cache) can cause. Webmon frees memory promptly while they work, and the TV usually has compressed swap of its own (shown above). With root, a swap file in the USB Webmon folder can add more. It is switched on whenever Webmon runs. Flash drives are slow and wear with writing, so only use it if you need it; FAT32 and ext4 drives work, NTFS does not.

Mod data

Mods keep their files per game and playthrough. A voxel world mod's map cache lives here, and when the game gives a playthrough a new id (for example after the app was closed during a cache build) the mod starts a new cache and the old one stays behind. Delete the ones you no longer need; the newest is usually the one in use. A deleted cache is rebuilt when needed.
